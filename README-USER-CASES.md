# Пользовательские сценарии

Этот документ описывает ожидаемое поведение локальной версии WoodCraft Market. Он нужен для проверки до публикации и не заменяет инструкции для производства или юридические документы.

## Покупатель

| Сценарий | Действия | Ожидаемый результат |
|---|---|---|
| Найти товар | Открыть витрину, выбрать категорию или ввести запрос | Отображаются подходящие карточки без перезагрузки страницы. |
| Купить товар | Добавить карточку в корзину, изменить количество, оформить | Сумма и доставка пересчитываются; данные заказа уходят в CRM только после подтверждения. |
| Спланировать комнату | Задать габариты, открыть каталог мебели, выбрать вид и добавить его | Предмет появляется в 3D-сцене внутри комнаты. Реальные виды мебели остаются в привычных категориях каталога. |
| Передвинуть предмет | Нажать предмет в сцене и тянуть цветные стрелки манипулятора | Предмет движется по выбранной оси X, Y или Z; границы комнаты соблюдаются. Клавиатура: стрелки — X/Z, Page Up/Down — Y. |
| Состыковать предметы | Подвинуть предмет к стене, полу, потолку или другому предмету | Магнит фиксирует касание по всем осям. Касание допустимо, фактическое наложение помечается как пересечение. |
| Посмотреть цену | Прокрутить ниже сцены до блока «Стоимость проекта» | Цена занимает отдельный широкий блок, выбранная комплектация и уровень фурнитуры видны сразу. Цена является ориентиром; техника, доставка, монтаж и замер в неё не входят. |
| Сохранить проект | Войти, заполнить название проекта и контакты, отметить согласие, сохранить | Сохраняются сцена, отделка, комплектация, контакты и название. При повторном открытии остаются характеристики предметов и положение. |
| Отправить расчёт | Нажать «Получить точный расчёт», заполнить контакты и отправить проект | Пользователь попадает к полям контактов; отправка выполняется отдельным явным действием. |

## Сотрудник и администратор

| Сценарий | Ожидаемый результат |
|---|---|
| Управление каталогом | Пользователь с правом `catalog:write` создаёт и редактирует категории и товары. |
| Раскрой | Пользователь с правом `cutting:run` передаёт детали в сервис раскроя, получает карты и PDF. |
| Работа с проектом | Пользователь с правом `planner:write` видит проекты в производственной части и экспортирует данные. |
| CRM и производство | Администратор ведёт заказ, материалы, склад, этапы и вложения с учётом ролей. |

## Ограничения и проверки

- Для сохранения и отправки проекта нужен аккаунт; проект доступен только владельцу или сотруднику с соответствующим правом.
- Нельзя добавить предмет больше комнаты или уменьшить комнату так, чтобы мебель в ней физически не помещалась.
- Расчёт листов асинхронный. Пока он обновляется, предыдущая цена не выдаётся за цену новой сцены.
- На телефоне планировщик складывается в одну колонку; блок стоимости идёт после 3D-сцены. Поля ввода используют размер, который не вызывает автоматическое масштабирование iOS.
- Оплата, отправка email/SMS и юридическое содержание шаблонов требуют настроек реального окружения и отдельной приёмки перед публикацией.
